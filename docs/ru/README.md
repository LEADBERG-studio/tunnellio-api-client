# Документация на русском

Это полный перевод раздела `docs/`. Английские файлы остаются на месте и
остаются каноническими для внешних читателей; здесь то же самое по-русски,
потому что README проекта написан по-русски, и документация не должна
переключать читателя на другой язык на первой же ссылке.

Если английский и русский текст разойдутся, правым считается английский:
править нужно оба файла в одном коммите, а не оставлять расхождение.

## Сборка и поставка
- [`BUILD_WINDOWS.md`](BUILD_WINDOWS.md) — как собрать `tunnellio.exe` из исходников
- [`RELEASES.md`](RELEASES.md) — как подготовить релизные артефакты: бинарник и универсальный архив

## Работа и эксплуатация
- [`CONFIGS.md`](CONFIGS.md) — конфиг по умолчанию, клиентские конфиги, правила перезаписи, имена запусков и порядок старта
- [`TCP_BRIDGE.md`](TCP_BRIDGE.md) — нативный TCP-мост (чистый Python, без внешних бинарников), флаг `--transport` и автоматический откат
- [`INTEGRATION.md`](INTEGRATION.md) — контракт для вызывающей программы, работа со случайным доменом и получение серверных параметров подключения по имени
- [`OPERATIONS.md`](OPERATIONS.md) — что клиент делает сверх голого SSH и как держать его в бою
- [`TESTING.md`](TESTING.md) — стратегия локальных проверок и команды

## Версии
- [`VERSIONING.md`](VERSIONING.md) — правила смены версии, изменения и чек-лист старта репозитория
