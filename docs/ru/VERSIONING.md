# Версии

## Где живёт версия
- каноническое значение: `pyproject.toml`;
- копия в пакете: `src/tunnellio/__init__.py`;
- список изменений для человека: `CHANGELOG.md`.

## Чек-лист смены версии
1. поднять версию в `pyproject.toml`;
2. поднять версию в `src/tunnellio/__init__.py`;
3. добавить запись в список изменений;
4. пересобрать бинарник;
5. пересобрать архив релиза.

## Чек-лист старта репозитория
1. `git init`
2. проверить `.gitignore`
3. `git add .`
4. `git commit -m "Initial import"`
5. позже добавить удалённый репозиторий и запушить

## Модель веток
Простая:

- `main` — состояние, готовое к выпуску;
- короткоживущие ветки под отдельные изменения.

## Стиль сообщений коммитов
Коротко и по делу, например:

- `Add Windows truststore TLS backend`
- `Add PyInstaller release scripts`
- `Document Windows binary build flow`
